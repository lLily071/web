# 奶龙美术学院跳转页

这是一个用于 GitHub Pages 的静态网页。访问页面后会显示学院标志和跳转提示，并在 3 秒后前往广州美术学院官网。网页将标志直接嵌入 HTML，并提供内嵌标签页图标，不依赖单独的图片请求。

## 发布

1. 将本文件夹中的 `index.html`、`nai-long-logo.webp` 和 `README.md` 上传至 GitHub 仓库根目录。
2. 在仓库设置中启用 GitHub Pages，并选择对应分支及根目录。
3. 等待部署完成后，使用 GitHub Pages 提供的网址访问。

跳转地址：<https://www.gzarts.edu.cn/>
